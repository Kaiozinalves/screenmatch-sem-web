# Screenmatch 📺

Este é um projeto de aprendizado em **Java** com **Spring Boot**, desenvolvido aula por aula na plataforma **Alura**. O objetivo é criar uma aplicação para consultar e gerenciar informações sobre séries e filmes utilizando APIs externas.

## 🚀 Sobre o Projeto

O **Screenmatch** permite buscar dados de séries de TV, incluindo temporadas e episódios, através de uma API de dados (como OMDB). É um projeto prático para aprender conceitos de Java, orientação a objetos, consumo de APIs e frameworks como Spring Boot.

## 🛠️ Tecnologias Utilizadas

- **Java 17** ou superior
- **Spring Boot**
- **Maven** para gerenciamento de dependências
- **API externa** para dados de séries (OMDB ou similar)

## 📋 Pré-requisitos

- JDK instalado
- Maven instalado
- Conta na API externa (se necessário, configure a chave no `application.properties`)

## ▶️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/screenmatch.git
   ```

2. Navegue até o diretório:
   ```bash
   cd screenmatch
   ```

3. Execute a aplicação:
   ```bash
   ./mvnw spring-boot:run
   ```

4. Acesse o menu interativo no terminal para interagir com a aplicação.

## 📁 Estrutura do Projeto

- `src/main/java/br/com/Alura/screenmatch/` - Código fonte principal
  - `Main/` - Classe principal com o menu
  - `models/` - Modelos de dados (DadosSerie, DadosTemporada, DadosEpisodio)
  - `services/` - Serviços para consumo de API e conversão de dados
- `src/main/resources/` - Arquivos de configuração (application.properties)
